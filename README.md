## 로컬 테스트

폴더 안의 `index.html`을 열어도 되지만, 브라우저 보안 설정에 따라 로컬 파일의 동작이 달라질 수 있으므로 간단한 로컬 서버 테스트를 권장합니다.

Python이 설치되어 있다면 폴더에서:

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`으로 접속합니다.

## GitHub Pages

1. 이 폴더 안의 파일을 GitHub 저장소 루트에 업로드합니다.
2. 저장소 Settings → Pages로 이동합니다.
3. Deploy from a branch를 선택합니다.
4. `main` 브랜치와 `/ (root)`를 선택해 저장합니다.
5. 생성된 Pages 주소를 친구들에게 보내면 됩니다.

## 다른 배포 Dashboard

## 오프닝

1. 첫 번째 이미지 + 자막 타이핑
2. 두 번째 이미지 + `그는 모르고 있었다..`
3. 세 번째 이미지 + 머리 안의 혈투 자막
4. 네 번째 이미지가 잠시 표시된 뒤 자동으로 게임 시작

SKIP, 다음 버튼, 화면 클릭, Space/Enter를 지원합니다.

## Roguelite 15-Wave Update

이번 버전은 기존 10웨이브 전투 구조를 유지하면서 15웨이브 로그라이트 캠페인으로 확장한 버전입니다.

### 캠페인
- Wave 1~5: 기존 상성 학습 구간 유지
- Wave 6~9: 염증 / DHT / 인슐린 조합 강화
- Wave 10: 스트레스 중간보스
- Wave 11: 수면 부족 등장
- Wave 12: 흡연 등장 + 높은 변이 확률의 러시
- Wave 13: 피지 과다 + 인슐린 / 튀김 탱커 조합
- Wave 14: 모든 주요 방해형 적이 섞이는 최종 방어선
- Wave 15: 3페이즈 최종보스 유전적 민감성

### 신규 적
- 수면 부족: 주변 타워 공격 효율 감소
- 피지 과다: 선천적인 피지 보호막 보유
- 흡연: 빠른 이동 + 주변 적 가속, DHT와 함께 있을 때 DHT 디버프 강화

### 최종보스 유전적 민감성
- Phase 1: DHT 소환
- Phase 2: 타워 사거리를 감소시키는 두피 민감 영역 생성
- Phase 3: 이동속도 상승 + 타워 휴지기 강제 진입

### 랜덤 증강
Wave 2 / 5 / 8 / 11 / 14 클리어 시 3개 중 1개 선택.
총 30개 증강이 구현되어 있으며 현재 증강은 중복 등장하지 않습니다.
증강 데이터는 `id / name / icon / rarity / category / description / condition / apply` 구조로 관리하고 `stackable` 속성을 향후 추가할 수 있습니다.

### 반랜덤 웨이브
매 게임 시작 시 15개 웨이브의 세부 수량이 새로 생성됩니다.
각 웨이브는 최소/최대 적 수량과 Threat Budget을 가지고 있어 핵심 테마를 유지하면서 일부 조합만 달라집니다.
다음 웨이브 미리보기에는 실제 생성된 적 구성, 위협도, 변이 확률이 표시됩니다.

### 적 변이
Wave 5부터 등장하며 후반으로 갈수록 확률이 상승합니다.
- 광폭
- 비대
- 재생
- 과민성
- 분열
- 완고함
- 피지 보호막
- 물리 내성
- 특수 내성

Normal 캠페인에서는 한 적당 최대 1개의 변이만 붙습니다.
적 위에 변이 외곽선/아이콘이 표시되고 마우스를 올리면 상세 효과를 확인할 수 있습니다.

### 조기 호출
기존 조기 웨이브 호출 유지.
연속 조기 호출 시 영양분 보너스가 추가되며 증강/보스 이벤트 웨이브에서는 이벤트 누락 방지를 위해 조기 호출이 제한됩니다.

### 전투 결과
클리어 시 다음 기록을 표시합니다.
- 남은 모낭 HP
- 영웅 레벨
- 총 처치 수
- 타워 건설 수
- 최종 진화 수
- 영웅 막타
- 조기 호출 수 / 최고 연속 호출
- 획득 영양분
- 최고 피해 타워
- 최다 처치 타워
- 획득 증강
- S/A/B/C 등급

### 안전장치
공격속도 버프가 극단적으로 중첩돼도 실질 공격 간격이 0.075초보다 짧아지지 않도록 제한했습니다.
재시작 시 증강, 변이, 반랜덤 웨이브, 보스 상태, 임시 버프와 통계가 모두 새로 초기화됩니다.

### 이번 버전에서 보류한 기능
선택형 무한 탈모 모드는 기본 15웨이브 캠페인 안정성을 우선하여 이번 패키지에는 포함하지 않았습니다.
